# AI Rule-Based Chatbot

## Internship Task 1 - CodSoft Artificial Intelligence Internship

### Project Description

This project is a simple AI Rule-Based Chatbot developed using Python.

The chatbot communicates with users through text input and provides predefined responses based on keywords and rules. It can answer basic questions related to Python, Artificial Intelligence, Machine Learning, Deep Learning, NLP, Computer Vision, Data Science, Neural Networks, and Chatbots.

The chatbot can also remember the user's name during the conversation.

## Features

- Responds to greetings such as hello, hi, and hey
- Understands basic user feelings
- Remembers the user's name
- Answers Python-related questions
- Explains Artificial Intelligence
- Explains Machine Learning and its types
- Explains Deep Learning
- Explains Natural Language Processing
- Explains Computer Vision
- Explains Data Science
- Explains Neural Networks
- Explains Rule-Based Chatbots
- Provides a fallback response for unknown questions
- Allows the user to exit by typing bye, exit, or quit

## Technologies Used

- Python 3
- Conditional statements
- Functions
- Loops
- String handling
- User input and output
